# Student Performance Analysis

This repository contains a data analysis of student exam performance. The dataset includes scores for math, reading, and writing, along with demographic information such as gender, race/ethnicity, parental level of education, lunch type, and test preparation course completion.

## Dataset Overview
The data is organized into groups (A through E) representing race/ethnicity. Each row includes:
- Gender (0/1)
- Group (A-E)
- Parental Level of Education
- Lunch Type (0/1)
- Test Preparation Course (0/1)
- Math Score
- Reading Score
- Writing Score
- Total Score
- Average Score

## Visualizations
The file `Students_Performance(Class 1 Data).pdf` contains charts showing:
- **Parental Level of Education to Maths Score:** A bar chart showing the distribution of math scores across different parental education levels.
- **Race Ethnicity to Reading Score:** A pie chart showing the proportion of reading scores by race/ethnicity group.
- **Parental Level of Education to Total Score:** A horizontal bar chart comparing total scores across parental education levels.

## Key Findings
- Students with parents holding an Associate's Degree or Some College tend to have higher total scores.
- Group C and Group D have the largest representation in the reading score distribution.
- Parental education level shows a correlation with student performance, with higher degrees generally associated with higher scores.
